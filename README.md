Mestrando em Ciências Naturais (UENF/LAMET, bolsista CAPES) e Licenciado em Ciências Biológicas (UFRJ). Trabalho com ciência de dados, climatologia, desenvolvimento web e educação em ciências.

**Portfólio completo:** publicado a partir da pasta [`docs/`](docs/) via GitHub Pages (Settings > Pages > Branch `main`, pasta `/docs`).

## Áreas

| Área | Foco |
|---|---|
| Ciência de dados | R, Python, DuckDB, séries temporais, Shiny |
| Climatologia e GIS | ERA5-Land, CHIRPS, INMET, SPI/SPEI, ETCCDI, Mann-Kendall, QGIS |
| Desenvolvimento web | JavaScript, p5.js, Three.js, FastAPI, GitHub Actions |
| Educação | Docência, STEAM, PBL, material didático, minicursos de R |

## Projetos em destaque

- **Pipeline climatológico do RJ** (mestrado): ERA5-Land e CHIRPS v3 para 92 municípios, com DuckDB.
- [**Bio-N-Class**](https://github.com/nchnogueira/Bio-N-Class): simulações interativas de ciências da natureza.
- **Simulador 3D de Stern-Gerlach**: Three.js/WebGL.
- [**MeteoRApp**](http://pexcca-uenf.shinyapps.io/MeteoRApp/): dados de estações em Shiny e Leaflet.
